# Zero Emoji Strict Discipline Skill

## Core Directive
Maintain absolute zero emoji usage across every system component, communication channel, and generated asset.

## Universal Scope
1. **User Communications**:
   - Never include any emoji characters in conversational text, answers, summaries, tables, or alerts.
2. **Video & Graphic Assets**:
   - Slide designs, HUD overlays, ruby cards, thumbnails, and banners must contain zero emojis.
   - Use clean typography, geometric outlines, and color contrast instead of emoji icons.
3. **YouTube & Metadata Pipelines**:
   - Titles, descriptions, tags, and playlist names must be completely free of emojis.
   - Any emoji scraper/regex must aggressively sanitize code points without stripping CJK characters.
4. **Codebase & Documentation**:
   - Comments, docstrings, JSON schema, markdown files, and commit messages must remain emoji-free.
